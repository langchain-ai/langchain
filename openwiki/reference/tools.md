## Deprecated Reference

This reference page is deprecated and superseded by the canonical documentation at **[/openwiki/concepts/tools.md](/openwiki/concepts/tools.md)**.

LangChain's tools extend the capabilities of language models by enabling them to interact with external systems and perform specialized tasks. Tools provide structured interfaces with input schemas, descriptions for model guidance, and execution logic that may be sync or async. For complete documentation covering tool types, schema management, tool calling workflows, lifecycle and state, error handling, binding to models, and advanced patterns, please refer to the current page linked above.
